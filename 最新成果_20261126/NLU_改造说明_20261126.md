# 轻量 NLU 改造说明（2026-11-26）

## 已完成

### 第 1 步：规则 NLU 补强
- 在 `voice_assistant.classify()` 前增加 `nlu.correct_asr()` 和 `nlu.normalize()`；
- 保留原有优先级：设备控制 > 天气 > 股票 > 时间 > 计算 > LLM；
- 规则未命中时，`nlu.match_intent()` 补同义词/模糊匹配；
- 已识别出的设备/计算/视觉任务直接走 `dispatch()`，不再被 `offline_agent` 的旧正则漏掉。

### 第 2 步：同义词、模糊匹配、ASR 纠错
- 新增 `nlu.py`：
  - 常见 ASR 形近纠错：开等→开灯、关登→关灯、天汽→天气、股漂→股票、坐子→坐姿等；
  - 同义词组：开灯/关灯/灯状态/天气/股票/时间；
  - 短句模糊匹配：只在规则未命中时启用，低置信度不直接执行；
  - 误触发保护：`我在等朋友` 不会被改成开灯。
- 无大模型模式（`cpu-local`）低置信度不再硬走 LLM，改为请求澄清。

### 第 4 步：低置信度才调用 LLM
- `cpu-local`：低置信度/未知意图 → 直接澄清，不调用 LLM；
- `mt200-local`：高置信度直接执行，低置信度交给本地 LLM；
- `hermes`：保持原流程，必要时走云端。

### 第 3 步：小型意图+槽位模型
- `tiny_nlu/train_nlu.py`：纯标准库 Multinomial Naive Bayes（字符 1–3 gram + 词片段）；
- `tiny_nlu/model.json`：约 16 KB；
- `tiny_nlu/nlu_model.py`：推理接口，置信度 < 0.80 或 margin < 0.15 返回 `LOW_CONFIDENCE`；
- **已接入 `voice_assistant.classify()` 的高置信度 fallback**：原规则/同义词未命中时才调用；灯控必须有“灯”，天气/股票/时间/视觉/拍照都有各自关键词安全闸，避免模型把噪声直接执行成设备动作；
- **SG885G 部署**：`/data/local/tmp/nlu/sg_nlu_server.py`，Termux Python CPU 推理，监听 `127.0.0.1:18094`；笔记本 `adb forward tcp:28094 tcp:18094` + `socat 0.0.0.0:18094 -> 127.0.0.1:28094`，RG 通过 `http://172.25.25.240:18094/nlu` 调用；服务不可用时自动回退 RG 本机模型；
- **不是 NPU**：当前是 SG885G CPU/Termux Python，尚未做 QNN/ONNX 转换，不能声称使用了 Hexagon NPU；
- 当前训练集为模板合成数据，holdout 准确率 **87.18%**，只证明管线可跑，**不能当产品指标**；
- 槽位仍由规则抽取，模型不生成 URL/命令/任意参数；
- SG885G 服务依赖 Termux Python 与已启动的进程；设备重启后需重新执行 `/data/local/tmp/nlu/start.sh`（当前未做 boot 自启）。

## 当前限制

- SG885G 当前没有 Python 运行时，不能在 SG 上直接跑训练脚本；
- 训练集是合成的，87.18% 不能当产品指标；
- 小模型尚未接入主路由，避免合成数据导致误路由；
- 真实上线前需要：
  1. 从 `voice.jsonl` / `voice.log` 收集 200–500 条现场语料；
  2. 人工标注 intent + slot；
  3. 重训并在 SG885G 侧用 Java/C/ONNX 或轻量 Python 运行时部署；
  4. 影子模式跑 1–2 周，对比规则路由和模型路由；
  5. 达到目标后再切换主路由。
