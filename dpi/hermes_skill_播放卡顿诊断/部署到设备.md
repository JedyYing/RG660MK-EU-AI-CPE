# 把「播放卡顿诊断」skill 部署到设备 Hermes

前提：本机 DPI 只读接口已在跑（`192.168.1.244:8770`，见上级目录《对接说明》），
且已拿到本机给的 token。以下步骤会**写设备**，执行前务必先备份。

## 1. 验证链路（只读，先做）

登设备 `ssh root@192.168.1.1`：

```sh
curl -s -m 6 -H "X-DPI-Status-Token: <本机给的token>" \
  http://192.168.1.244:8770/dpi/status
```

能返回 JSON（含 `dpi_service` / `stream_status`）即链路通。设备无 curl 时用
`wget -qO- --header="X-DPI-Status-Token: <token>" http://192.168.1.244:8770/dpi/status`。

## 2. 放 token 到设备（0600，不入 skill 明文）

```sh
mkdir -p /data/ai_cpe/demo/data
printf '%s' '<本机给的token>' > /data/ai_cpe/demo/data/dpi-status-token
chmod 600 /data/ai_cpe/demo/data/dpi-status-token
```

## 3. 备份现有 skills，再写入本 skill

```sh
cp -r /data/ai_cpe/hermes/.hermes/skills /data/ai_cpe/hermes/.hermes/skills.bak
mkdir -p /data/ai_cpe/hermes/.hermes/skills/embedded/rg660mk-video-diagnose
# 把本目录的 SKILL.md 传到上面这个路径（scp 或粘贴）
```

从本机传：

```sh
scp "SKILL.md" \
  root@192.168.1.1:/data/ai_cpe/hermes/.hermes/skills/embedded/rg660mk-video-diagnose/SKILL.md
```

## 4. 重启 Hermes gateway（只重启 gateway，不动网络）

```sh
# 按设备实际服务名重启 Hermes gateway 进程（不要动网络/DPI）
```

## 5. 验收

对 Hermes 说「视频卡不卡 / 帮我诊断下播放」，看它是否：
调用了接口、返回了分级结论（✅/🟡/🔴/⏸/⚠️）、并附了取数时间。

## 回滚

```sh
rm -rf /data/ai_cpe/hermes/.hermes/skills/embedded/rg660mk-video-diagnose
cp -r /data/ai_cpe/hermes/.hermes/skills.bak/* /data/ai_cpe/hermes/.hermes/skills/
# 重启 Hermes gateway；本机侧接口回滚见上级《对接说明》
```
