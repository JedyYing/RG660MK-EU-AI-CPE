5.2 为什么 200 TOPS 只有约 13 token/s

  1. Decode 串行：第 N+1 个 token 必须等待第 N 个 token，batch=1 无法把 token 并行铺开。
  2. 访存墙：4.4 GB 级 bundle 按每token读取一次4.4 GB bundle作极简假设，13 tok/s约对应57 GB/s搬运量级；bundle不等同纯权重，此数不是实测带宽；NPU 经常在等 LPDDR、KV 和同步。
  3. 峰值条件不同：200 TOPS 假设低精度、稀疏、大矩阵、大 batch、高复用和峰值频率；单用户 LLM decode 正好是窄矩阵、低复用。
  4. 非矩阵开销：解量化、归一化、采样、KV Cache、FastRPC 与 CPU/NPU 同步不贡献标称 TOPS。
  5. 忙不等于算满：Q6 可在 94.59% 时间处于工作状态，但其中包含等待和数据搬运，算术阵列未必满吞吐。
阶段粗略算法量估算占 200 TOPS说明
Decode 13 tok/s2 × 7B × 13 ≈ 0.18 TOPS约0.09%（口径不可直接对比）算法量级推算，不是硬件计数器
Prefill 608 tok/s2 × 7B × 608 ≈ 8.5 TOPS约4.3%（口径不可直接对比）输入 token 可并行，利用率明显更高
散热：CPU 8B 曾把最高热区推到 114.8°C，并需要强制终止。NPU 长请求补测达到 83.8°C。必须保持风扇，建议 85°C 等待、90°C 拒绝/中止、降至 75°C 后恢复。

6. W4A16 大白话解释

一句话：模型的“长期知识”用 4 bit 压缩存放，回答当前问题时的“临时草稿”用 FP16 计算。
部分大白话比喻技术含义
W4把几十亿条菜谱压缩编号存放权重约4 bit/参数；70亿参数理论约3.5 GB；FP16同规模约14 GB。仅权重约缩至1/4，整体内存不会必然减少75%，还有scale、词表、图、激活和KV
A16做当前这道菜时用较精细的草稿纸A16表示FP16激活；主要计算路径通常以FP16处理，但不能由量化名称推出每个算子或累加器都为FP16，需QNN图与算子profile验证

W4A16 不表示整个模型是 FP16，也不表示输出文字只有4bit。它选择了“最大头的静态权重强压缩、变化大的临时结果保精度”的折中。

7. 9.76 GiB 是否能支持 7B INT8

7.1 单看权重：可以

7B INT8：7,000,000,000 byte ≈ 6.52 GiB
8B INT8：8,000,000,000 byte ≈ 7.45 GiB

所以 9.76 GiB available 能放下“权重文件”。但模型运行还需要 QNN 图、激活、KV Cache、DMA/shared buffer、bridge、dsh、Ubuntu 和安全余量。

内存项7B INT8 粗估风险
INT8 权重6.5–7.5 GiB不同模型参数量、量化元数据会变化
QNN 图/工作区/激活约1.5–3 GiB现有W4路径固定开销并不小
KV Cache无通用固定值；FP16 KV约为2×层数×KV头数×头维度×token数×2字节。32层、8 KV头、128维时4K约0.5 GiB，8K约1 GiB；32 KV头则增至4倍上下文越长越吃内存
dsh + bridge + 系统需分别测量；available已经扣除当前系统占用，不可把系统占用再从同一available预算重复扣除MT200无swap，必须留余量
DMA/FastRPC 映射不能只由free判断普通内存可用时仍可能 fastrpc_mmap failed
判断：7B W8A8 + 1024 context 经过专门优化后可能勉强运行；7B W8A8 + 4K/8K 风险高。available 包含可回收页缓存，不代表所有内存都能被 DSP/NPU 以所需方式映射。

7.2 值不值得试

值得做一次受控 PoC，但不值得替代长上下文 W4A16 成为主线。W8A8 可能略微改善量化质量，却将权重流量接近翻倍；decode 已经受访存限制，因此还可能变慢。如果 W8A8 仍只有1024 context，DSH工具和长对话问题完全没有解决。

测试条件通过线立即回退条件
先保留当前 W4A16，停止但不删除W8A8 bundle 可独立加载、中文正常破坏当前可用路径
确认真正W8A8 QNN包、量化及上下文→短提示→512→768；1K总上下文必须为输出和系统提示预留空间10轮无OOM/无FastRPC映射失败fastrpc_mmap failed 或 OOM
记录内存/温度/速度/质量建议整机保留至少1 GiB available，按MemTotal与MemAvailable核对；温度<90°C；不把进程RSS当全设备内存available<1 GiB时暂停，<500 MiB或温度≥90°C立即中止；冷却到≤75°C后人工确认再恢复
同题A/B质量收益足以抵消速度与上下文损失仅精度微升、上下文仍1K

更有价值的厂商 A/B 是：7B W4A16 + 8K context 对比 7B W8A8 + 4K context，而不是只把当前1K包从W4换成W8。
