## 复测期间发现并修复的问题

1. Token 用量面板数字严重偏低（今日显示 9.8 万 tokens / ¥0.37）
   - 根因 A：设备端 `ssh` 是 dropbear 客户端，不认 `-o`（`-o BatchMode=yes` 报
     `unknown configuration option`），笔记本两个 `state.db` 全部拿不到
   - 根因 B：脚本写死笔记本 IP `192.168.1.244`，DHCP 实际下发 `192.168.1.212`
   - 根因 C：overlay 重置后 crontab 里的 `*/15 token_cost.py` 丢失，数据停在 14:45
   - 修复：`-y -T -i <key>` 兼容 dropbear；按 MAC `00:e0:4c:55:75:98` 从 `/tmp/dhcp.leases`
     解析笔记本 IP；恢复 `*/15` 定时。修复后 `sources_ok=3`、`errors=[]`，
     跨日实测 213.7 万 tokens ≈ ¥7.07（当日晚间口径）
   - 代码：`services/tools/token_cost.py`（提交 56b6306）

## 已知限制与口径

- 旧域名 `spencer-supporters-sized-interstate.trycloudflare.com` 在 DNS 层已 NXDOMAIN：
  quick tunnel 域名与进程绑定，进程退出即删除，**不可恢复**；当前域名为唯一有效地址。
- quick tunnel 域名在 cloudflared 重启或板子重启后会变，由 `board_tunnel_keeper.sh`（cron `*/2`）
  刷新 `/www/board_url.txt`。要固定地址需自有域名 + 命名隧道，或 Tailscale Funnel。
- 视觉项按最终口径：画面有人/无人、坐姿正常/异常、身份是否匹配都属于场景状态，
  只要 YOLO/姿态/人脸链路执行成功即 pass；本次 100 轮全部记录「画面内无人，链路已执行」。
- 静音巡检（`full:false`）不上传照片、不外放 TTS；完整演示验收需另跑 `full:true`。
