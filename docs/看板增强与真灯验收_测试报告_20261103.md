### 2.3 NPU 指标（本地模式）

看板芯片实测文本：

```
NPU  deepseek-7b-npu · 算力规格 200 TOPS · 利用率 15.5%（近60s·1次） · 最近推理 9.3 s
```

对应 `/state.npu`：

```json
{"elapsed_ms": 9272, "model": "deepseek-7b-npu", "chars": 25, "ok": true,
 "calls_60s": 1, "busy_ms_60s": 9272, "util_60s": 15.5, "mode": "mt200-local"}
```

- 口径：利用率 = 近 60s 内推理占用时长 ÷ 60s（`9272ms / 60000ms = 15.5%`）。
- 无推理请求时显示 `0.0%（近60s·0次）`；服务重启后统计清零但芯片仍常驻（用 `llm.model` 兜底）。
- 200 TOPS 为规格值（项目文档 7 处记载），与利用率分开标注。

## 4. 边界与未覆盖

1. NPU 硬件占用率（SM/DSP busy%）该 BSP 未暴露；现为推理占空比口径。
2. 200 TOPS 为规格值，非实测算力。
3. Token 费用为按官方峰谷价的估算，非账单实扣。
4. 涂鸦云通道未启用（缺 Access ID/Secret）；启用后优先级高于 board-led。
5. 本地模式依赖笔记本在线（192.168.1.244:18091 → SSH → MT200:8090）。
