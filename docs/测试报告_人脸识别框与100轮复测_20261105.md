## 四、复测期间发现并修复的问题

1. **PIL 不可用**：aicpe-board 进程 `import PIL` 报 `libtiff-*.so.6.2.0` 缺失 →
   改为解析 JPEG SOF 段取宽高。
2. **ai_service 429**：并发请求撞推理信号量 → 加 `_FACE_INFER` 排队。
3. **失败结果被缓存**：服务恢复后同一帧仍返回旧错误 → 只在 `ok` 时写缓存。
4. **提示图错位**：遮挡提示图会替换画面 → 判定遮挡时删除 `FACE_LAST`。
5. **8765 无自启**：板子重启后视觉服务缺失 → `/faces` 失败时限频拉起 `start_ai.sh`。
