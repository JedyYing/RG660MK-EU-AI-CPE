## 4. 环境说明（重要）

### 4.1 MiniNAS 的 LAN 地址不可达，但服务经 ZeroTier 可达

- `nas_host()` 优先探测 `192.168.1.244`，当前该地址在 CPE 和 PC 上均为 ARP INCOMPLETE / 100% 丢包；
- 本轮第 7 项明确记录「CasaOS 在线（经 **172.25.25.240**）」，说明回退到了 ZeroTier 地址；
- 原因：MiniNAS 就是 x86 主机 `sh-d-l`（本机 Docker 栈：Immich / HA / MQTT / CasaOS），`.244` 是旧局域网地址，当前不在任何网卡上；机器现有地址为 `192.168.1.180`（WiFi）、`192.168.1.212`（USB 网卡）、`172.25.25.240`（ZeroTier）；
- 影响：第 4 项 RTT 由局域网个位数毫秒升至 10–25ms；第 3/7/8 项经 ZT 正常通过；若 ZT 也断，则第 3 项 `skip`、第 4/7/8 项 `fail`；
- 可选修复：在 PC 的 CPE 侧网卡上增加 `192.168.1.244/24` 别名，或把 `nas_host()`/`llm_gateway.LOCAL_HOSTS` 的局域网地址改为当前 `.212`（DHCP 会变，ZT 地址更稳，暂不改）。
