# RG660MK · Hermes Token 用量统计（2026-09-17）

## 方案
- **数据源**：设备本地 SQLite `/data/hermes/.hermes/state.db`
  - `sessions` 会话级汇总；`session_model_usage` 按模型/任务细分；`messages` 提供时间戳
- **计费口径**（核对 Hermes `agent/usage_pricing.py`）
  - `input_tokens` = 缓存未命中输入；`cache_read_tokens` = 缓存命中输入
  - `output_tokens` = `completion_tokens`（**已包含推理**）；`reasoning_tokens` 为其子集
  - 用量口径 = `input + output`，缓存命中单列（不可与 reasoning 重复相加）
- **按天归属**：Hermes 按会话记账，用「当天消息条数」为权重把会话用量分摊到天（总量精确、单日为估值）
- **人民币计价**：DeepSeek 官方价；高峰 = 工作日 9:00-12:00 / 14:00-18:00，其余半价；按消息时间分布做峰谷混合
