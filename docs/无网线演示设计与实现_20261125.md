# RG660MK 无网线演示设计与实现

- 日期：2026-11-25
- 适用：笔记本与 RG660MK 不在同一现场（无网线直连）时，仍能完整演示 8099 十大功能
- 现场条件（实测）：笔记本接入公司 Wi-Fi `Quectel`（10.83.103.75/20），RG660MK 走 5G（WAN 10.121.134.116）

## 1. 目标与约束

| 项 | 要求 |
|---|---|
| 浏览器入口 | `http://127.0.0.1:18099/` 不变（PM/同事的书签不用改） |
| 板子出口 | 5G 蜂窝，不依赖公司 Wi-Fi |
| 笔记本出口 | 公司 Wi-Fi，不因插网线断网 |
| 云端中继 | 优先考虑阿里云 47.116.191.31（结论：不可行，见第 5 节） |

## 2. 最终链路

```
浏览器 → 127.0.0.1:18099（demo18099_proxy.py，自动注入 X-Demo-Token）
       → ZeroTier 172.25.25.224:8099（板子 8099）
       → 回退 192.168.1.1:8099（网线在位时）

板子 → ZeroTier 172.25.25.240:18091（笔记本 llm_gateway）
     → socat 127.0.0.1:18090 → adb forward tcp:28080 → SG885G:8080
```

要点：
- **18099 代理**（`~/scripts/demo18099_proxy.py`）：监听 127.0.0.1:18099，向上游注入 `X-Demo-Token`（读 `~/.config/rg660/demo_token`，0600），ZT 优先、LAN 回退。
- **8099 令牌**：看板启用 DEMO_TOKEN 后，浏览器无需手工带 token；令牌不会出现在 URL/页面源码里。
- **SG885G 转发守护**（`~/scripts/sg885g_forward.sh` + `sg885g-forward.service`）：每 10 秒检查 adb 设备，自动建立 28080/28081 转发，USB 掉线重插后自愈。
- **板端端点**：`llm_gateway.LOCAL_ENDPOINT = http://172.25.25.240:18091/v1/chat/completions`（改用 ZT 地址，网线不在也能到笔记本）。

## 3. 插网线不断网（笔记本侧）

NetworkManager 档案 `rg660-lan`（按 MAC 00:E0:4C:55:75:98 匹配 USB 网卡 enx00e04c557598）：

```
ipv4.method      manual
ipv4.addresses   192.168.1.212/24
ipv4.never-default yes     ← 关键：不抢默认路由
ipv4.route-metric 700      ← 低于 Wi-Fi（600）
```

效果（实测）：插网线后默认路由仍是 `default via 10.83.96.1 dev wlp0s20f3 metric 600`，外网 200；到板子走 `192.168.1.0/24 dev enx...`。

## 5. 为什么阿里云不能当中继（实测结论）

| 检查 | 结果 |
|---|---|
| 47.116.191.31 端口扫描 | 仅 22 开放；80/443/8080/9993/18099 全部 closed（安全组） |
| 板子 5G APN | 封 22/443（ssh 到公网返回运营商拦截） |
| 推论 | 板子无法主动连阿里云，阿里云也无法反向连板子（无入站隧道）→ 不能做中继 |

若要启用阿里云中继，必须二选一：
1. 安全组放行 80/443（HTTP 隧道）或 9993/UDP（ZeroTier moon）；
2. 给板子换允许 443 的 APN。

## 6. 实测数据（2026-11-25）

- 18099：HTTP 200；ZT 到板子 RTT 240–495 ms，阶段性 0% 丢包
