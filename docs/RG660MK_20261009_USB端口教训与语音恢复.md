## 关键教训（钉死）
1. **hub 上游必须插板子上"正确的那个口"**（错口=永不枚举、零电气事件）。判定：
   `ssh root@fdc3:8285:b409::1 'ls /sys/bus/usb/devices/'` 应能看到 `1-1`、`1-1.2`、`1-1.3` 等条目。
2. 板子 USB host 模式=常驻（rc.local `echo 2 > .../11591000.usb/mode`）；正确值 `MTU3_DR_OPERATION_HOST`。系统内想把端口"翻面"成 device 的请求会被强制挡回（日志 `op_mode 2, skip set role`）。
3. 摄像头采集用**厂商独立程序 `/data/camview/camview`（自带 UVC 实现，不依赖内核 uvcvideo 模块）**；网页=8090。
4. 声卡映射：card1=C270(其自带麦，不用)、**card2=UGREEN CM564（用 plughw:2,0，录音/放音增益=255/100%）**。
5. 看板 8099=按需在线（keep-alive 已从 1h 调至 6h）；重拉方式：桌面「RG660MK巡检」或设备 `run_inspection.sh`。
6. 一键恢复流水线：`scripts/rg660mk_recover.sh`（all / qos / link）。
