## 三、现场解决的问题（2026-11-05 ~ 11-07）

| 问题 | 根因 | 解决方法 | 验证 |
|---|---|---|---|
| 音箱喊三次没反应 | `whisper-cli` 与 `ggml-base.bin` 在断电后丢失，每次 ASR 抛 `FileNotFoundError`，转写恒空 | ASR 默认引擎切到常驻 paraformer（`:6006`，模型完好） | 日志无 FileNotFoundError；asr p50 0.94 s |
| 喊一次不响应、要喊两次 | `asleep` 只被置 True、从未置 False，说过一次「休息」后整场都在休眠态 | 唤醒成功后立即 `asleep=False` | 代码级修复 + 变体补齐 |
| 「你好小皮」第一次被忽略 | paraformer 现场把它听成「你好小陈」，变体表未覆盖 | 补小陈/小晨/小成/小城到三处变体表 | `is_sleep_wake("你好小陈")` 返回 True |
| 问「现在几点」答错 | ASR 把环境音拼在问句后，时间正则用 `fullmatch` 整句匹配 → 落到大模型，模型答「没有查时间的工具」 | 改为「句首命中且 ≤30 字即按本地时间处理」 | `classify("现在几点…噪音")` → LOCAL_DATE_TIME |
| 公网演示打不开 | 板子断电重启，cloudflared quick tunnel 换域名，旧域名 NXDOMAIN | 从 `/www/board_url.txt` 取新域名，判活后更新二维码 | 新域名 root/state/snap 均 200 |
| 摄像头画面延迟高 | 公网单帧 45 KB，经隧道 2.4~3.9 s；画面 3 s 才刷新一帧 | 外网请求缩图（13.7 KB）、内网返回原图；刷新 1.5 s；局域网恢复 MJPEG 推流 | 局域网 34 ms / 公网 1.15~2.44 s |
| WiFi 信号显示三个 dBm | chip 把所有关联 STA 拼在一起，还混入 `iw` 返回的非法值 | 只显示一个有效值；设备名移到「接入终端」清单 | HONOR-90 -74 dBm + 清单 |
| 「有线 2」但只有一根网线 | ARP 里 `192.168.1.106`（STALE、无租约）被算成在线；MLO 多链路 MAC 重复计数 | 排除 STALE；按 WiFi 设备租约 IP 去重 | 4 → 3（WiFi 2 · 有线 1） |
| 连说三次「你好小皮」无响应 | 展馆广播/旁人聊天持续触发 VAD，用户的喊话被切碎成「的的的」重复串，被防幻觉规则 drop；非休眠态又误用严格判定（要求「你好」前缀），转写成「小皮」时直接丢弃 | ① 非休眠判定改 `is_wake`（接受「小皮」短变体）② 待机录音窗口 8 s→5 s ③ 采集增益 140→190 并写入 `aicpe-boot` 持久化 | 重启后一次唤醒成功；日志出现 `WAKE(asr-fallback)` 与 `time_fast_ok` |
| 问「现在几点」感觉等了 30 秒 | 并非报时慢：`time_fast_ok` 本地快路径命中，TTS 走缓存；30 秒里绝大部分是唤醒重试（每轮 8 s 录音 + 1 s ASR） | 同上：缩短录音窗口 + 放宽唤醒判定 | 报时本身 1~2 秒；唤醒一次成功 |

## 四、当前遗留与处置结果（2026-11-07 下午更新）

1. **KWS 声学唤醒 —— 已评估，当前不可部署**（不是配置问题，三条路径全堵死）：
   - pip 安装 sherpa-onnx：清华源可达，但 `onnxruntime` 无 aarch64-musl wheel（设备是 OpenWrt musl，manylinux 不可用）
   - GitHub releases 下载静态包：github.com 超时，ghfast.top 403 / gh-proxy.com 404 / kgithub.com 无响应
   - 复用现有二进制：`sherpa-onnx-offline` 与 `websocket-server` 均不含 keyword-spotter 功能
   - 替代（已实施）：待机录音 8 s→5 s、唤醒应答缓存 0.000 s、非休眠接受「小皮」短变体、增益 140→190；
     实测唤醒链路从约 2.5 s 降到 1.2~1.8 s
2. **NTP —— 已启用**（2026-11-07 12:30）：`system.ntp.enabled=1`，服务器改为阿里云 + cn.pool，
   sysntpd 运行中，实测与本机时差 0 s
3. **语音自检 —— 已加入开机自检**：`demo_boot_check.sh` 新增 6/7 音频段，检查 card2、采集增益、
   能独占时实测 2 秒录音字节数，被占用时改看最近日志活动
4. **公网域名不固定**：cloudflared quick tunnel 与进程绑定，断电/重启必换域名，二维码需同步更新
