二、能力边界是怎么测出来的

2.1 真人测试（16 帧，有 ground truth）

测试对象：本人，男，实际年龄 50。摄像头正对，室内顶光，距离 50–80 cm。

指标实测值说明
性别13/13 正确，置信 0.956–0.999多时段、多姿态重复采样，全部 male
年龄中位 55.6，范围 47.8–63.6相对真值 +5.3 岁；单帧最大偏差 +13.6 岁
年龄段5/5 正确（全部"中年"）阈值修正后（<60 中年 / ≥60 老年）
阈值踩坑记录：初版把年龄段划成 <55 中年 / ≥55 老年，50 岁被判"老年"。这是实现错误，不是模型问题。已改为 <18 / <40 / <60 / ≥60。

2.2 为什么年龄只报段位

16 帧原始值：47.8 / 50.1 / 53.8 / 54.0 / 63.6 / 55.0 / 56.1 / 56.1 / 56.4 / 56.4 / 58.7 / 55.0 / 58.1 / 55.6 / 56.6 / 56.5

跨度 15.8 岁，16 帧里 13 帧偏高，方向一致 → 系统性偏差而非随机噪声。若报精确值，同一个你在不同时刻会得到 48 岁到 64 岁；但"中年"这个判断稳定成立。

取舍：对外只返回 age_band，精确值仅在内部用于算段位，不写入响应。

三、情绪识别为何移除

3.1 两个数据集，同一批模型，结果差 20 个百分点

数据集性质ViT-AffectNetFER+
FER2013（700 张）实验室摆拍，正面大头照56.0%49.6%
RAF-DB（554 张）真实场景，互联网图片36.2%19.9%
随机猜 7 类基准线14.3%14.3%
商用 API（参考）云端65–80%—

实验室数据好看，是因为 FER2013 全是正面、居中、光照均匀的大头照。真实场景里换个光照、歪个头，准确率直接掉到 36.2%——比随机猜好 22 个百分点，但离可用线（70%）差一半。

3.2 六种融合策略都救不回来

策略FER2013RAF-DB问题
仅 ViT-AffectNet56.0%36.2%几乎不会判 neutral（1%）
仅 FER+49.6%19.9%几乎只会判 neutral（91%）
融合 A（FER+ neutral>0.90 优先）60.6%—实验室最高，真实场景失效
融合 B（FER+ neutral>0.70 优先）58.4%—neutral 保住 85%，其他类被拖累
融合 C（ViT 说 neutral 才用 FER+）56.0%—等于纯 ViT，无改善
融合 D（取最大概率者）59.7%28.6%真实场景比单模型更差
关键发现：两个模型的错误在真实场景不互补——FER2013 上看起来互补（一个偏 neutral、一个偏负面），是因为那个数据集的 happy/neutral 太典型。换到 RAF-DB，融合反而互相拖累（36.2% → 28.6%）。

3.3 还试过：人脸对齐（负优化）

预处理RAF-DB 准确率
ArcFace 5 点对齐后喂 ViT32.0%
bbox 直接裁剪喂 ViT39.9%

该 ViT 在 AffectNet 上训练时的预处理不是 ArcFace 对齐，强行对齐反而 -7.9 个百分点。这条也写进结论：对齐不是万能的，要按模型训练时的预处理来。

决策：三项能力（性别/年龄/情绪）里，性别和年龄段实测可靠，情绪在端侧小模型上触到天花板。移除情绪，只交付前两项，并在文档与接口里明确标注，不做模糊表述。

4.1 为什么推理放在本机，而不是设备

试过设备端，六个组合全部失败：

尝试结果
ncnn 1.0.20261020 / 20241226 / 20231027load_param/load_model 返回 0，但 extract() 必然段错误（exit 139）
numpy 2.4.6 与降级 1.26.4同样崩溃，排除 ABI 问题
num_threads=1 + 关 packing + 关 fp16同样崩溃，排除优化指令集问题
CPU 指令集Cortex-A55 有 asimddp/asimdhp，不是硬件能力问题

结论：ncnn 的 pybind11 绑定在该 musl 环境有兼容性缺陷，不是参数能解决的。C++ 静态链接路径可行（现有 face_runner 就是这么做的），但需交叉编译工具链，周期 1–2 小时。

当前代价：依赖笔记本在线。笔记本关机/断网，该功能不可用。但这条不影响 8099——8099 的设备端链路完全独立。

4.3 模型预处理（踩过的两个坑）

坑 1：模型内置归一化，外面不能再归一化。
genderage.onnx 图里自带 Sub(127.5) → Mul(1/128)。若外面再做一次 (x−127.5)/128，输入被压成极小值，随机噪声、纯灰图、真人脸会输出完全相同的结果（female 0.609 / 35.1 岁）。必须传原始 0–255。
坑 2：必须 RGB，不能用 BGR。
cv2 默认读 BGR。实测同一张女性人像：BGR → male（错），RGB → female 0.973（对）。

方法：停服务测 8 次 → 启服务测 8 次 → 重复 3 轮，消除设备负载随时间漂移的影响。

轮次服务停止（中位）服务运行（中位）差

差异 0.2 ms，且方向来回跳（第 2 轮运行反而更快）→ 说明是设备自身在 load 6.4 下的抖动，不是服务引入的。

5.3 40 次连续推理压测

指标结果
