# AI CPE 五大功能一键演示套件

**用途**：双击即可自动遍历运行 AI CPE 五大智能化功能，过程**实时可视化**（进度卡片 + 现场摄像头画面 + 滚动日志），
用于①版本质检自测 ②向领导/客户演示。

## 一键运行（在电脑桌面双击）
- `AI_CPE功能演示.desktop` —— 双击后：SSH 到设备启动演示 → 自动打开浏览器看板 `http://192.168.1.1:8099/`
- 首次需输入设备 SSH 密码（`Terminal=true`，窗口内提示）
- 无桌面环境可用 `bash run_demo.sh`；静音质检加 `--no-audio`

## 看板内容
- 5 张功能卡片：实时状态（待运行/运行中/通过/失败）+ 关键证据 + 耗时
- 右侧：**C270 现场实时画面**（1 秒刷新）+ 滚动日志
- 顶部进度条；完成后显示总结横幅与报告路径

## 五项功能是怎么验的（都走生产路径，不造假）
| # | 功能 | 实测内容 |
|---|---|---|
| 1 | AI 智能语音对话 | 服务存活 + 常驻 ASR(sherpa/paraformer :6006) + **现场真实录音转写** + 大模型对话 + TTS 播报(CM564) |
| 2 | AI 视觉检测 | 抓帧 → YOLOv8n 目标检测 + pose 姿态 → **坐姿判定**（阈值同 posture_check.py）+ 人脸身份识别（Immich） |
| 3 | 飞书自然语言图片检索 | 自然语言指令（云海/泰晤士/最近/日期）→ Immich 检索 → 命中文件清单；飞书通道绑定校验 |
| 4 | 视频卡顿智能排障 | **主动拉流测帧率/码率** + 单帧时延 + 局域网/公网链路丢包与 RTT + netdiag 全景 + 摄像头服务状态 → 结论 |
| 5 | 智能家居控制 | Tuya 云连通 + **实际下发开关指令** + 状态回读差分（该型号未暴露开关 DP，以云平台受理为准） |

## 报告产出
- Markdown：`reports/AI_CPE_功能演示报告_<时间戳>.md`（含逐项证据）
- JSON：`reports/AI_CPE_功能演示_<时间戳>.json`（供二次统计）

## 已知限制
- 画面内无人时：坐姿显示"画面内无人（链路已执行）"、人脸显示"没有识别到人脸"——这是真实结果，不是故障
- 该型号灯泡状态接口不返回开关 DP，故以"指令被云平台受理"为通过依据
- 大模型通道：设备侧走 `ai.phicotek.com/api/llmrouter/v1`；需保证 token 预算充足（思考型模型会先消耗 reasoning token）
