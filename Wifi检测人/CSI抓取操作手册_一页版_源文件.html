RG660MK Wi-Fi CSI 抓取操作手册

MediaTek T930 + MT7992 · Connac3(Logan) · fw CSI 022 · OpenWrt 23.05 —— 一页版
依据：Connac3 CSI Spec v1.2（2024-01-10）+ 本机 5 轮实测（2026-11-25）｜适用：2.4G / 5G（Kite 无 6G）
一句话结论：本板 CSI 原始 I/Q 能抓（2.4G 64 / 5G 80MHz 256 子载波，单帧 351B，TLV 与规范一致）； 但当前固件的 proc 模式只锁存 1–2 个 PPDU、单链锁定无效、netlink 无连续上报 → 连续 CSI 序列拿不到，人体走动感知暂不可行（固件能力问题，已提 MTK 工单）。

1开工前 3 条确认

ls /proc/net/wlan/        # 需有 csi_data_0/1
which mwctl hostapd_cli   # 定命令路径
dmesg | grep -i csi       # 驱动是否注册

没有 /proc/net/wlan/csi_data_* = 这版驱动没开 CSI，先找原厂要带 CSI 的固件，别去调算法。

2命令速查（Logan / Connac3）

动作命令
配置过滤mwctl ra0 set csi=2-3-0-34
opt1=2 配置；opt2~4=帧类型/ping长度/MAC/时间戳/协议（仅 opt1=2 时给）
开抓（proc）mwctl ra0 set csi=1 5G 用 rai0
落盘cat /proc/net/wlan/csi_data_0 > csi.bin
停抓mwctl ra0 set csi=0（先停再 Ctrl-C）
重臂csi=0 + csi=1（约 10Hz）

MT76 路径：hostapd_cli -i phy0-ap0 set_csi 2,3,0,34 → set_csi 1 → dump_csi 3000,csi_2g.json → set_csi 0。

3数据格式（实测 TLV，小端）

Magic 0xAABBCCDD(4B) | Length(2B) | TLV...
TLV = Tag(1B) + Len(2B LE) + Value
 Tag 2 Timestamp(4B,us)   3 RSSI(int8)   4 SNR
     5 BW(0=20 1=40 2=80 3=160 4=320)
     6 PrimaryCh   7 TX_MAC(6B)
     8 CSI_I(2×子载波)  9 CSI_Q(同长)  10 Extra(4B)

值是有符号 14-bit 复数，I/Q 分开存；振幅 √(I²+Q²)、相位 atan2 自己算。子载波数：20M=64 / 40M=128 / 80M=256；11ax/be 的 tone 会采样对齐到 11ac，别按 ax 的 tone 数解析。

4解析骨架（Python）

import struct
b = open('csi.bin','rb').read()
assert b[:4] == b'\xdd\xcc\xbb\xaa'
i = 4; n = struct.unpack('<H', b[i:i+2])[0]; i += 2
while i < len(b):
    tag = b[i]; ln = struct.unpack('<H', b[i+1:i+3])[0]
    v = b[i+3:i+3+ln]; i += 3 + ln
    if tag == 8: I = struct.unpack('<%dh' % (ln//2), v)
    if tag == 9: Q = struct.unpack('<%dh' % (ln//2), v)

5本板实测判据（MT7992 / fw 022）

项实测
单帧大小 / 子载波351B（2.4G 64 子载波）；5G 80M 256 子载波 OK
连续采集只锁存 2 个 PPDU（4链×2=8 帧）；csi_buffer_cnt 10s 恒为 used(8)
重臂副作用重复回放旧帧：Beacon 相邻帧相关 1.000；90s 9218 帧 pkt_sn 仅 255 值
单链锁定无效：csi=2-7-0-0 后 rx_path 仍均匀（2440/2370/2262/2146）
链间一致性同 pkt_sn 四链幅度差 5 倍（921/857/165/426）≫ 走动引起的 1–5%
netlink无连续上报：ra0-auto-1000 仅 1 条，-100 10s 内 0 条
帧率Beacon 触发 0.17–0.5 fps；QoS Data + 重臂 76–108 fps（含回放帧）
高频重臂约 2000 次后 2.4G 引擎停摆，只能 wifi restart 恢复

6能不能做人检测：判据

  • 先抓 30s 静止 + 30s 走动，画子载波振幅瀑布图；人走动应出现 1–10Hz 多普勒带。
  • 本板现状：走动/静止样本无差异（回放帧占多数）→ 先解决连续采集，再谈算法。
  • 可信样本要求：真实新 PPDU 占比高、相邻帧相关 < 0.4（本板实测 > 0.9 = 回放）。

7坑与纪律

  • 没帧就没 CSI：抓的时候必须打流（ping/UDP/视频），空闲链路只能靠 Beacon（0.17–0.5 fps）。
  • cat proc 是流式的：控制时长，别写爆 /data（板子 overlay 仅 21MB）。
  • 抓 CSI 占空口时间：演示/压测期间禁止同时抓。
  • 重臂只作实验手段，不能进产品（回放 + 打挂引擎）。
  • 解析前先验 Magic 与小端长度，TLV 按 Tag 跳读，别按固定偏移硬解。

8抓到没抓到：30 秒自检

  • ls -l csi.bin 每秒变大 → 有帧；一直不变 → 没帧（去打流）。
  • 首 4 字节应为 DD CC BB AA（小端 Magic）。
  • csi_buffer_cnt 停在 used(N) 不动 = 只锁存了 N 帧，需重臂但别高频（见 ⑤）。
