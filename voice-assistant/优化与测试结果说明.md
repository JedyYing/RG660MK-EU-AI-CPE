# RG660MK 智能音箱优化 —— 结果说明

对照《RG660MK 智能音箱优化设计 V1.0》对现有部署 `voice-assistant/voice_assistant.py` 做了优化，并在本机跑了离线验收测试。

## 一句话结论

设计文档点名的 bug（问天气被误答成时间、1+1 反复没听清走大模型）已在代码层修好；不依赖真实音频/联网的逻辑（路由分类、30/60 秒双超时、turn_id 防串话）已用离线测试验证，**27 项断言全绿**。真正的麦克风→whisper→播报端到端测试需要在 RG660MK 设备上跑，那部分我够不到，如实标注在下方。

## 离线已验证（本机真实执行）

- **T01** 1+1 → 本地算 2，不进 Hermes
- **T02** 今天星期几 → 本地时间
- **T03** 今天上海什么天气 → 天气（原代码这里必挂，现已修复）
- **T04** 北京明天会下雨吗 → 天气，城市=北京
- **T05** 相对论 → 兜底 Hermes
- **T06 / T10** 把灯打开 / 开灯 → 设备控制 on
- **T07** 模拟 35 秒返回 → 30 秒播"请稍等。"、35 秒播结果、不误报未学会
- **T08** 模拟 70 秒返回 → 30 秒请稍等、60 秒未学会、70 秒迟到结果被丢弃
- **T09** 连续三轮 turn_id 严格递增；旧轮迟到结果因 current 已切新轮被丢弃

回归：拍照/上传/坐姿/人脸/识别/关灯/天气/时间/闲聊分类全部仍正确。
